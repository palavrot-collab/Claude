# Button

The rounded call-to-action pill from the flyers: one per frame, at the bottom of the composition.

- Provide: the label (a full action phrase in Hebrew, e.g. "פירוט לו״ז והרשמה") and a link or click handler.
- `.yr-btn-bark` (brown) is the primary CTA on photo backgrounds and posters; `.yr-btn-brand` (green) on light, airy layouts; `.yr-btn-quiet` for secondary actions.
- `.yr-btn-lg` on posters and slides; default size on web pages and dashboards.
- Do: keep the label on one line; use `>>` as the only arrow, after the text, as the flyers do.
- Don't: put two filled pills side by side, or set the label in the body face.
