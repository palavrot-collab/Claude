# StatTile

One number with its label, meaning and source: the unit of every dashboard and data slide.

- Provide: label (what is measured), value (with sign and unit), one-line meaning, and the source. A tile without a source is not shown.
- `.is-positive` colors an improvement `positive`; pair it with the sign, never color alone.
- Figures are left-to-right inside the right-to-left tile so `−18%` reads correctly.
