# DateLine

The event's day, date and time on one line, framed above and below by the green `rule`.

- Provide: day (`יום ג׳`), date in `D.M.YY`, time range `H:MM-H:MM`, in that right-to-left order, separated by `|`.
- Default size for posters (date style, 40px); `.yr-date-sm` for web, email and stories with less room.
- The figures use tabular numerals so they do not jitter when animated.
- Don't: spell out the month, add a year in four digits, or drop the rules.
