# רפואת יער ישראל: content world

Source files for the Forest Therapy Israel visual line. The live, browsable version is the design system artifact:
https://claude.ai/artifact/Dq66uueRWD5o91Wbvfhc2A

- `design-system/README.md`: the brand book (voice, color, type, imagery, motion, data, lectures, formats). Read it before making anything.
- `design-system/tokens.json`: colors (light and dark), type styles, spacing, radii, shadows.
- `design-system/components/`: component styles (`bundle.css`) and a preview plus guidelines per component, including `SlideFrame` for lecture decks.
- `design-system/assets/`: logo (forest and white), the three pillar icons, photography and the reference flyers.

In previews, images point at the artifact's asset store (`/_blob/<id>`); the same files sit under `design-system/assets/`.
