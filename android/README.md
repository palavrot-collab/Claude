# מצפן

מסך בית לאנדרואיד שמחליף את הלאנצ'ר הרגיל: בלי אייקונים, עם הלו"ז והמשימות של היום, אפירמציות, קיצור לעוזר ב-Claude, ועצירה לפני אפליקציות מסיחות ואחרי גלילה רצופה.

אפליקציה אישית להתקנה ישירה (APK). אין לה הרשאת אינטרנט, וכל המידע נשאר בטלפון.

## מה יש בפנים

| אזור | מה קורה |
|---|---|
| מסך הבית | שעה, תאריך, אפירמציה (הקשה מחליפה), הקבוע בלו"ז היום עם הדגשה של הפגישה הבאה, המשימות הפתוחות (הקשה סוגרת, לחיצה ארוכה מציגה את ההערה), ורשימת טקסט של האפליקציות שהצמדת |
| אפליקציות | רשימת טקסט עם חיפוש. אפליקציות מסיחות מוסתרות עד שמקלידים את השם שלהן |
| מסך ההשהיה | לפני אפליקציה מסיחה: נשימה וספירה לאחור (10 שניות, ועוד 5 על כל ניסיון נוסף באותו יום), אפירמציה, המשימה הבאה מהלוח, חלופות (פריט מהספרייה, אפליקציות מוצמדות, תרגיל קצר), ורק אז אפשרות להמשיך ל-5, 10 או 20 דקות |
| סוף הזמן | כשהדקות שהקצבת נגמרות והאפליקציה עדיין פתוחה, מסך ההשהיה חוזר |
| גלילה | אחרי X דקות של גלילה רצופה באפליקציה מסיחה (ברירת מחדל 5), האישור מתבטל ומסך ההשהיה חוזר |
| גווני אפור | כבוי, רק בתוך אפליקציות מסיחות, או לפי שעות |
| Claude | הכפתור פותח את אפליקציית Claude עם תקציר מוכן: השעה, הלו"ז של היום, מה פתוח, מה נסגר, יעדי השבוע וכמה פעמים ניסית לפתוח אפליקציה מסיחה. התקציר גם מועתק ללוח |
| ספרייה | קישורים שבחרת מראש. שיתוף קישור מכל אפליקציה אל "שלח למצפן" מוסיף אותו |
| תרגילים | דקה של נשימה, שלוש תודות (נשמר ביומן מקומי), מבט על יעדי השבוע |

## התקנה

1. להוריד את `app-debug.apk` מהרצת ה-Actions האחרונה (לשונית Actions, ההרצה "Android APK", תחת Artifacts) ולהתקין בטלפון.
2. לפתוח את מצפן, ובהגדרות: **מסך הבית של הטלפון** ולבחור במצפן.
3. בהגדרות: **שומר הקשב** ולהפעיל את "מצפן · שומר הקשב" בהגדרות הנגישות.
   באנדרואיד 13 ומעלה, אפליקציה שהותקנה מקובץ חסומה כאן כברירת מחדל: הגדרות הטלפון, אפליקציות, מצפן, שלוש הנקודות למעלה, "אפשר הגדרות מוגבלות", ואז לחזור ולהפעיל.
4. בהגדרות: לבחור אפליקציות מסיחות ואפליקציות למסך הבית, ולערוך את האפירמציות.

בלי שלב 3 ההשהיה פועלת רק כשפותחים אפליקציה מתוך מצפן, ולא כשמגיעים אליה מהתראה או מקישור.

### גווני אפור (לא חובה)

אנדרואיד לא נותן לאפליקציה רגילה לשנות את צבעי המסך. צריך אישור חד-פעמי ממחשב עם adb:

```
adb shell pm grant app.matzpen android.permission.WRITE_SECURE_SETTINGS
```

## החיבור ללוח השבועי

מצפן קורא את הלוח באותו מבנה שבו הוא כבר נבנה בארטיפקט השבועי (המערך `D`). הוא מקבל אותו בשלוש דרכים, והוא מזהה לבד את הפורמט:

1. קישור `matzpen://week?d=<JSON בקידוד base64url>`
2. שיתוף טקסט או קובץ אל "שלח למצפן" (JSON, או קוד המקור של הדף)
3. העתקה ללוח, ואז בהגדרות: "להדביק לוח שבועי מהלוח"

הפורמט:

```json
{
  "title": "לוח שבוע 8-15.11",
  "goals": [{ "t": "כותרת היעד", "p": "פירוט" }],
  "days": [
    {
      "name": "שני 9.11",
      "date": "2026-11-09",
      "mode": "כותרת היום",
      "fixed": [["10:15", "פגישה"], ["16:00-17:30", "בלוק עבודה"]],
      "items": [{ "id": "m-1", "d": "תחום", "t": "המשימה", "p": "הערה", "m": "10 דק'", "hot": 1 }]
    }
  ]
}
```

`date` לא חובה: אם הוא חסר, התאריך נגזר מהשם ("שני 9.11").

כדי שהלוח יגיע לטלפון בהקשה אחת, להוסיף להנחיה של הבריף השבועי:

> הוסף לראש הלוח שני כפתורים, "שלח למצפן" ו"העתק למצפן". שניהם בונים `payload = {title: document.title, goals: [...], days: D}`. הראשון הוא קישור אל `matzpen://week?d=` ואחריו ה-payload כ-JSON בקידוד base64url (UTF-8). השני מעתיק את ה-JSON ללוח.

```js
const payload = {
  title: document.title,
  goals: [...document.querySelectorAll(".gl")].map(g => ({
    t: g.querySelector("b").textContent, p: g.querySelector("span").textContent })),
  days: D,
};
const json = JSON.stringify(payload);
const b64 = btoa(String.fromCharCode(...new TextEncoder().encode(json)))
  .replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
sendLink.href = "matzpen://week?d=" + b64;
copyButton.onclick = () => navigator.clipboard.writeText(json);
```

סימון "סגרתי" במצפן נשמר בטלפון בלבד ואינו חוזר לארטיפקט. Claude רואה אותו דרך התקציר שהכפתור שולח.

## מגבלות ידועות

- לא ניתן לשלוט באפליקציית Claude מבפנים. הקיצור מעביר לה טקסט בשיתוף, ואם היא לא מקבלת אותו התקציר נמצא בלוח להדבקה.
- זיהוי הגלילה נשען על אירועי נגישות שהאפליקציות עצמן שולחות, ולכן הדיוק משתנה בין אפליקציות.
- החיכוך אינו נעילה: אפשר לכבות את שירות הנגישות או להחליף לאנצ'ר. זו בחירה מכוונת בגרסה הזאת.
- הקובץ `keystore/sideload.keystore` הוא מפתח חתימה להתקנה אישית בלבד, והוא שמור בריפו כדי שכל גרסה תותקן מעל הקודמת. הוא אינו מתאים להפצה בחנות.

## בנייה

```
cd android
gradle assembleDebug
```

Kotlin, ללא תלויות חיצוניות, minSdk 26. ה-workflow ב-`.github/workflows/android.yml` בונה APK בכל דחיפה.
